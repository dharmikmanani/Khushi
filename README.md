
# ❤️ Romantic Proposal Website

A fully animated cinematic proposal website built using HTML, CSS, and JavaScript.

Designed to create an unforgettable digital love confession experience with emotional storytelling, dreamy visuals, and interactive animations.

---

## ✨ Features

* Fullscreen animated intro
* Floating hearts & glowing effects
* Interactive love letter
* Memory gallery section
* Relationship timeline
* Romantic proposal scene
* Confetti & celebration animations
* Emotional cinematic ending
* Mobile responsive design
* Soft aesthetic UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* GSAP Animations
* Optional Three.js Backgrounds
